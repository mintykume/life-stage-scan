# Output templates

Use this file when writing the reading. Headings can be translated or renamed to fit the person's language and register. Keep the order.

## Quick read (in chat)

```
**Your chapter: [Name]**
[Two sentences: where they are and what this chapter is for.]

**Under the surface:** [the core tension in one or two sentences, with evidence labels]

**Best next move:** [the one advance] — because [which layers it serves]. Keep [other areas] at [minimum].

**Make it livable:**
- [romanticize idea tied to their story]
- [style or explore idea]
- [one more, from the most relevant module]

**Next 7 days:**
- Today: [≤15-minute move]
- This week: [three actions]

**One question to sit with:** [question]
**What would change this reading:** [the information that would flip it]
```

## Full scan (a document)

### 1. Your Chapter

The chapter name as a heading, then one paragraph on what this chapter is for: its developmental task.

### 2. The Layers

| Layer | What I see | Evidence | Confidence |
|---|---|---|---|
| Season & situation | … | [said] … / [shown] … | high |
| Build | … | … | medium |
| Strivings | … | … | … |
| Meaning-making | … | … | low–medium |
| Story | … | … | … |

Follow the table with two or three sentences on anything the table can't carry.

### 3. Under the Surface

Name the core tension (one, at most two). Give the evidence from at least two layers. Then say what it might mean, as a hypothesis.

### 4. The Leverage Point

Name the single move, then explain why it shifts several layers at once.

### 5. Three Paths & the Best Next Move

| | A: Deepen | B: Pivot | C: Wild card |
|---|---|---|---|
| Path | … | … | … |
| Fit | 1–5 | | |
| Compounding | | | |
| Reversibility | | | |
| Contribution | | | |
| Aliveness | | | |
| Cost (5 = cheap) | | | |

Then:

- **Best next move:** what it is, and why it wins.
- **Maintain:** each other area at its minimum.
- **Checked:** what was looked up (current conditions, existing work), with links.

### 6. How You Contribute From Here

- **Rare combination:** …
- **One step behind you:** …
- **Smallest public form:** …

### 7. Life Texture

Include only the two or three relevant modules: Romanticize, Style, and/or Explore & learn. Every idea is tied to something they said or showed.

### 8. The Plan

| Horizon | Action | Why (layer) | Smallest version | Working if… | Change course if… |
|---|---|---|---|---|---|
| Today | | | | | |
| This week | | | | | |
| 30 days | Main quest / side quests / ritual | | | | |
| 90 days | Milestone + proof artifact | | | | |
| This year | Direction | | | | |

Add a **Stop / pause** list with one to three items.

### 9. Questions to Sit With

Three open questions, specific to this person.

### 10. What Would Change This Reading

The information that would flip the recommendation. This invites the person to correct you.

End with a one-line offer to revisit.

## Writing rules

- **Specific.** Trace every recommendation to something they said or showed. The generic test: if a line could go in anyone else's reading, cut it or make it specific.
- **Vivid, not mystical.** Chapter names and rituals can be poetic. Claims about the person stay evidence-labeled.
- **Short sentences, their language.** Write in the person's language and register.
- **Honest.** At least one observation should be something they might not want to hear, said kindly.
- **Scoped.** No numbers for health, weight or diet. No confident claims about current programs, deadlines or prices without a search.
