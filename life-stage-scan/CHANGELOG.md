# Changelog

All notable changes to life-stage-scan. Versions follow [Semantic Versioning](https://semver.org/).

## 1.0.0 — 2026-11-26

- First public version.
- Six-layer read (season & situation, build, strivings, meaning-making, story, tensions) with [said] / [shown] / [read] evidence labels and confidence levels.
- Intake in rounds: snapshot, deep scan (question bank), threads.
- Three odyssey-style paths scored on six criteria; one primary move with maintenance minimums.
- Contribution-from-current-stage step.
- Life texture modules: romanticize (savoring), personal style, explore & learn, plus on-request modules.
- Plan horizons from today to this year, with stop/pause list and falsifiers.
- Reference files: question bank, layers, life texture, output template, fictional worked example, sources with evidence levels.
- Five eval cases in `claude plugin eval` format.
- README, design notes, validator, packaging script, and CI that attaches the upload ZIP to each GitHub Release.
